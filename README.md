# 🚀 Features
🔍 Browse jobs by tech stack, domain, and experience level

👤 Separate dashboards for Job Seekers and Employers

🧠 Filter-based search with real-time updates

📋 Post and manage job listings

📧 Easy account creation, secure login system

🎯 Focused on high-demand niches: Web, Mobile, Cloud, DevOps, Data Science, and more

# 🛠️ Built With
```
Frontend: React, HTML, CSS

Backend: Node.js, Express

Database: MongoDB

Auth: JWT-based login

Hosting: Netlify / Render
```

#Clone the repo
```
git clone https://github.com/divanshArora3/dev.jobs.git
cd dev.jobs
```
# Setup Backend
```
cd server
npm install
npm run start
```
# Setup Frontend
```
cd client
npm install
npm start
```
# Create .env in /server
```
PORT=5000
MONGO_URI=your_mongo_connection_string
JWT_SECRET=your_secret_key
```

# 👨‍💼 How It Works
```
Create an Account – Sign up as a Job Seeker or Employer.

Post or Browse Jobs – View filtered jobs or post your own.

Hire or Get Hired – Apply, shortlist, and track progress.
```
